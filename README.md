# نقل الملفات 2.0 (موبايل / ويندوز / لينكس)

- كل جهاز بيبعت وبيستقبل (موبايل ↔ كمبيوتر ↔ كمبيوتر).
- بيكتشف الأجهزة اللي على نفس الواي فاي لوحده، بدون IP.
- بيبعت ملفات وفولدرات كاملة.
- على أندرويد بيكمل في الخلفية عن طريق Foreground Service.

## البناء
ارفع المحتوى على GitHub وشغّل Actions ← Build all (راجع الدليل).

## ملاحظات
- أول تشغيل على ويندوز: اسمح للتطبيق في الـ Firewall (الشبكات الخاصة).
- لينكس: لو ufw شغال: sudo ufw allow 40405/tcp && sudo ufw allow 40404/udp
- الملفات بتتحفظ في Downloads/FileTransfer.
- لازم الواي فاي ما يكونش بيعزل الأجهزة عن بعض (AP isolation / Guest network).
